# A05 — Track live network connectivity

**Medium** · Disjoint set union

## The challenge

Process commands ["connect", u, v] and ["linked", u, v] for n isolated servers. connect adds an undirected link; linked returns whether a path currently connects them. Return booleans for linked commands only.

**Constraints:** 0 <= n <= 100000; 0 <= commands <= 200000; all referenced IDs are in range.

**Function to implement:** `def solve(n, commands):`

## Examples

1. Input arguments: `[4,[["linked",0,1],["connect",0,1],["linked",0,1],["connect",1,2],["linked",0,2]]]` → expected output: `[false,true,true]`
2. Input arguments: `[1,[["linked",0,0],["connect",0,0]]]` → expected output: `[true]`
