# A05 — Track live network connectivity

**Medium** · Disjoint set union

## The challenge

Process commands ["connect", u, v] and ["linked", u, v] for n isolated servers. connect adds an undirected link; linked returns whether a path currently connects them. Return booleans for linked commands only.

**Constraints:** 0 <= n <= 100000; 0 <= commands <= 200000; all referenced IDs are in range.

**Function to implement:** `def solve(n, commands):`

## Examples

1. Input arguments: `[4,[["linked",0,1],["connect",0,1],["linked",0,1],["connect",1,2],["linked",0,2]]]` → expected output: `[false,true,true]`
2. Input arguments: `[1,[["linked",0,0],["connect",0,0]]]` → expected output: `[true]`

### A. From baseline to the right data structure

Re-running DFS after every connectivity update is expensive. Disjoint set union maintains component representatives under additions and answers linked queries quickly.

### B. Invariant or recurrence and why it works

Each representative is the root of a parent forest. Union by size joins different roots; path compression preserves root identity while shortening paths. A linked query compares find(u)==find(v).

### C. Work through a real example

- Function arguments: `[4, [["linked", 0, 1], ["connect", 0, 1], ["linked", 0, 1], ["connect", 1, 2], ["linked", 0, 2]]]`
- Expected output: `[false, true, true]`

For n=4: merge(0,1), merge(2,3), linked(0,3)→False, merge(1,2), linked(0,3)→True. Root IDs may vary; connectivity is the invariant.

### D. Executable reference implementation

```python
"""Reference answer for A05. See the problem statement before reading.
"""
def solve(n, commands):
    parent = list(range(n)); size = [1] * n
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    out = []
    for kind,u,v in commands:
        a,b = find(u),find(v)
        if kind == 'linked':
            out.append(a == b)
        elif a != b:
            if size[a] < size[b]: a,b = b,a
            parent[b] = a
            size[a] += size[b]
    return out
```

### E. Complexity derivation

O(n) initialization; q operations are O(q·α(n)) amortized with path compression and size union, where α is inverse Ackermann. Space O(n+number of query results).

### F. Failure modes that expose memorized solutions

If the endpoints are already connected, do not join a root to itself or inflate component size. Ordinary DSU cannot efficiently support **edge deletions**.
