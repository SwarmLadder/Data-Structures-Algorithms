# A06 — Minimum cable cost to connect all offices

**Medium** · Minimum spanning tree

## The challenge

For n offices and undirected weighted links [u,v,cost], return the minimum total cost to connect all offices. Return -1 if impossible. Parallel edges and zero-cost links are allowed; n=0 returns 0.

**Constraints:** 0 <= n <= 100000; 0 <= links <= 200000; costs are nonnegative integers.

**Function to implement:** `def solve(n, links):`

### A. From baseline to the right data structure

Kruskal sorts candidate links by cost and uses DSU to add an edge only when it connects distinct components.

### B. Invariant or recurrence and why it works

The selected edges form an acyclic forest. The MST cut property guarantees the cheapest edge crossing a current component cut can be part of an optimal spanning tree; accepting it is safe. Stop after n−1 edges.

### C. Work through a real example

- Function arguments: `[3, [[0, 1, 5], [1, 2, 1], [0, 2, 9]]]`
- Expected output: `6`

For edges 0–1 cost 1, 1–2 cost 2, 0–2 cost 5, accept the first two, skip the expensive cycle edge; total cost 3. A disconnected graph cannot reach n−1 accepted edges and returns −1.

### D. Executable reference implementation

```python
"""Reference answer for A06. See the problem statement before reading.
"""
def solve(n, links):
    if n <= 1:
        return 0
    parent = list(range(n)); size = [1]*n
    def find(x):
        while parent[x] != x:
            parent[x] = parent[parent[x]]
            x = parent[x]
        return x
    total = used = 0
    for u,v,cost in sorted(links,key=lambda e:e[2]):
        a,b = find(u),find(v)
        if a == b: continue
        if size[a] < size[b]: a,b = b,a
        parent[b] = a; size[a] += size[b]
        total += cost; used += 1
        if used == n-1: return total
    return -1
```

### E. Complexity derivation

O(E log E) sorting and O(E·α(V)) DSU operations, O(V+E) storage including sorted edges; auxiliary DSU O(V).

### F. Failure modes that expose memorized solutions

Do not sum every cheap edge without rejecting cycles. A minimum spanning **forest** differs from a tree when the graph is disconnected.
