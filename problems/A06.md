# A06 — Minimum cable cost to connect all offices

**Medium** · Minimum spanning tree

## The challenge

For n offices and undirected weighted links [u,v,cost], return the minimum total cost to connect all offices. Return -1 if impossible. Parallel edges and zero-cost links are allowed; n=0 returns 0.

**Constraints:** 0 <= n <= 100000; 0 <= links <= 200000; costs are nonnegative integers.

**Function to implement:** `def solve(n, links):`

## Examples

1. Input arguments: `[3,[[0,1,5],[1,2,1],[0,2,9]]]` → expected output: `6`
2. Input arguments: `[4,[[0,1,1],[2,3,1]]]` → expected output: `-1`
