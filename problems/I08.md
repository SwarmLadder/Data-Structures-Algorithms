# I08 — Kth largest distinct response size

**Medium** · Heap / top k

## The challenge

Return the kth largest distinct integer in nums, not the kth largest element counting duplicates. k is valid.

**Constraints:** 1 <= len(nums) <= 100000; 1 <= k <= number of distinct values.

**Function to implement:** `def solve(nums, k):`

### A. From baseline to the right data structure

Sorting every value uses O(n log n). First deduplicate, then keep a min-heap of k largest distinct seen values; the root is the current kth largest.

### B. Invariant or recurrence and why it works

After processing each distinct value, heap contains the largest min(k, number distinct so far) values. If full, a new value matters only when it exceeds the root; replace the root then.

### C. Work through a real example

- Function arguments: `[[3, 2, 1, 5, 6, 4], 2]`
- Expected output: `5`

For [4,7,7,3,9] with k=2, distinct values are {4,7,3,9}. Heap eventually holds [7,9], so result is 7, not duplicated 7.

### D. Executable reference implementation

```python
"""Reference answer for I08. See the problem statement before reading.
"""
def solve(nums, k):
    import heapq
    heap = []
    for x in set(nums):
        if len(heap) < k:
            heapq.heappush(heap, x)
        elif x > heap[0]:
            heapq.heapreplace(heap, x)
    return heap[0]
```

### E. Complexity derivation

Constructing set(nums) uses expected O(n) time and O(n) memory; processing d distinct values costs O(d log k), plus O(k) heap storage.
