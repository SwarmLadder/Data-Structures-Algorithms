# I02 — Shortest log fragment containing required tokens

**Hard** · Sliding window

## The challenge

Return the shortest substring of text containing all characters of required, respecting their multiplicities. Break ties by earliest starting position. Return "" if impossible or required is empty.

**Constraints:** 0 <= len(text) <= 100000; 0 <= len(required) <= 10000; ASCII.

**Function to implement:** `def solve(text, required):`

## Examples

1. Input arguments: `["ADOBECODEBANC","ABC"]` → expected output: `"BANC"`
2. Input arguments: `["a","aa"]` → expected output: `""`
