# I02 — Shortest log fragment containing required tokens

**Hard** · Sliding window

## The challenge

Return the shortest substring of text containing all characters of required, respecting their multiplicities. Break ties by earliest starting position. Return "" if impossible or required is empty.

**Constraints:** 0 <= len(text) <= 100000; 0 <= len(required) <= 10000; ASCII.

**Function to implement:** `def solve(text, required):`

## Examples

1. Input arguments: `["ADOBECODEBANC","ABC"]` → expected output: `"BANC"`
2. Input arguments: `["a","aa"]` → expected output: `""`

### A. From baseline to the right data structure

Brute force enumerates every window and checks required multiplicities. A deficit counter makes expansion and shrinking amortized linear.

### B. Invariant or recurrence and why it works

The count map records how many of each required character are still missing; negatives mean surplus. `missing` is total unmatched **occurrences**. Expand until missing=0, then shrink while valid, recording best windows first.

### C. Work through a real example

- Function arguments: `["ADOBECODEBANC", "ABC"]`
- Expected output: `"BANC"`

For text=ADOBECODEBANC, required=ABC, the first valid window ADOBEC is length 6. Later BANC is valid and shorter, so return BANC. If required contains two As, one A is not enough.

### D. Executable reference implementation

```python
"""Reference answer for I02. See the problem statement before reading.
"""
def solve(text, required):
    from collections import Counter
    if not required:
        return ''
    need = Counter(required)
    missing = len(required)
    left = 0
    best = (len(text) + 1, -1, -1)
    for right, char in enumerate(text):
        if need[char] > 0:
            missing -= 1
        need[char] -= 1
        while missing == 0:
            if right - left + 1 < best[0]:
                best = (right - left + 1, left, right + 1)
            need[text[left]] += 1
            if need[text[left]] > 0:
                missing += 1
            left += 1
    return text[best[1]:best[2]] if best[1] >= 0 else ''
```

### E. Complexity derivation

O(|text|+|required|) expected time plus O(answer length) slicing, and O(distinct required characters) counters. Both boundaries move monotonically.

### F. Failure modes that expose memorized solutions

Checking distinct letters rather than counts fails when required has repeats. Empty requirements should return empty string; ties should use the defined earliest-window rule.
