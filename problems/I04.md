# I04 — Longest request window with at most k services

**Medium** · Sliding window

## The challenge

Return the longest contiguous substring containing at most k distinct characters. Return zero for k=0 or an empty string.

**Constraints:** 0 <= len(text) <= 100000; 0 <= k <= 100000; ASCII.

**Function to implement:** `def solve(text, k):`

## Examples

1. Input arguments: `["eceba",2]` → expected output: `3`
2. Input arguments: `["aa",1]` → expected output: `2`
