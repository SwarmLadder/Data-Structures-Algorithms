# I04 — Longest request window with at most k services

**Medium** · Sliding window

## The challenge

Return the longest contiguous substring containing at most k distinct characters. Return zero for k=0 or an empty string.

**Constraints:** 0 <= len(text) <= 100000; 0 <= k <= 100000; ASCII.

**Function to implement:** `def solve(text, k):`

## Examples

1. Input arguments: `["eceba",2]` → expected output: `3`
2. Input arguments: `["aa",1]` → expected output: `2`

### A. From baseline to the right data structure

Exhaustively testing substrings costs O(n²) or more. For a longest substring with at most k distinct characters, maintain an expand/shrink window and character counts.

### B. Invariant or recurrence and why it works

The window contains at most k distinct characters after the shrink loop. Adding right may violate this; removing leftmost characters restores validity. Only then compare its length with global best.

### C. Work through a real example

- Function arguments: `["eceba", 2]`
- Expected output: `3`

For text=eceba and k=2, ece has characters e,c and length 3; adding b causes three distinct keys, so shrink until valid. The best remains 3.

### D. Executable reference implementation

```python
"""Reference answer for I04. See the problem statement before reading.
"""
def solve(text, k):
    if k == 0:
        return 0
    from collections import defaultdict
    count = defaultdict(int)
    left = best = 0
    for right, char in enumerate(text):
        count[char] += 1
        while len(count) > k:
            old = text[left]
            count[old] -= 1
            if count[old] == 0:
                del count[old]
            left += 1
        best = max(best, right - left + 1)
    return best
```

### E. Complexity derivation

O(n) expected time: each character enters once and leaves once; O(min(k+1,alphabet)) window-count map memory.

### F. Failure modes that expose memorized solutions

Remove dictionary keys when counts reach zero, otherwise len(count) overstates distinct characters. Handle k=0 as zero even on nonempty text.

### G. Transfer the technique

Variant: count the number of substrings with exactly k distinct characters using at-most(k) minus at-most(k−1).
