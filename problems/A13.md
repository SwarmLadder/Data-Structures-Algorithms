# A13 — Prefix suggestions for command names

**Medium** · Trie / lexicographic search

## The challenge

Return the lexicographically smallest k *distinct* words that start with prefix. If none match, return []. Word order in the input is irrelevant; k=0 means no suggestions.

**Constraints:** 0 <= len(words) <= 50000; total characters <= 200000; lowercase words; 0 <= k <= 100.

**Function to implement:** `def solve(words, prefix, k):`

## Examples

1. Input arguments: `[["car","card","care","cart","cat","dog"],"car",3]` → expected output: `["car","card","care"]`
2. Input arguments: `[["z","a","b","a"],"",3]` → expected output: `["a","b","z"]`

### A. From baseline to the right data structure

Scanning every word for every prefix query costs O(total text) per query. A trie shares common prefixes and lets queries start directly at the requested prefix node.

### B. Invariant or recurrence and why it works

Each trie edge consumes one character; terminal marker means a whole inserted word ends there. Starting from the prefix node, visiting children in lexicographic order emits unique suggestions in the required order, stopping after k.

### C. Work through a real example

- Function arguments: `[["car", "card", "care", "cart", "cat", "dog"], "car", 3]`
- Expected output: `["car", "card", "care"]`

For words [car,cat,cart,dog] and prefix ca, lexicographic suggestions are car,cart,cat. For prefix z, no trie path exists and result is empty.

### D. Executable reference implementation

```python
"""Reference answer for A13. See the problem statement before reading.
"""
def solve(words, prefix, k):
    root = {}
    for word in set(words):
        node = root
        for ch in word:
            node = node.setdefault(ch,{})
        node['#'] = True
    node = root
    for ch in prefix:
        if ch not in node: return []
        node = node[ch]
    if k == 0: return []
    result = []
    stack = [(node,prefix)]
    while stack and len(result) < k:
        current,path = stack.pop()
        if '#' in current:
            result.append(path)
        for ch in sorted((c for c in current if c != '#'),reverse=True):
            stack.append((current[ch],path+ch))
    return result
```

### E. Complexity derivation

Building the trie costs O(total characters) expected dictionary work. Query costs O(prefix length + visited descendant work + output-string construction); worst-case space is O(total characters plus traversal/output).

### F. Failure modes that expose memorized solutions

Do not assume `dict` child insertion order equals lexical order; children are sorted explicitly. Duplicate words must not produce duplicate suggestions.
