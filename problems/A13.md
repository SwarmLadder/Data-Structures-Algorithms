# A13 — Prefix suggestions for command names

**Medium** · Trie / lexicographic search

## The challenge

Return the lexicographically smallest k *distinct* words that start with prefix. If none match, return []. Word order in the input is irrelevant; k=0 means no suggestions.

**Constraints:** 0 <= len(words) <= 50000; total characters <= 200000; lowercase words; 0 <= k <= 100.

**Function to implement:** `def solve(words, prefix, k):`

## Examples

1. Input arguments: `[["car","card","care","cart","cat","dog"],"car",3]` → expected output: `["car","card","care"]`
2. Input arguments: `[["z","a","b","a"],"",3]` → expected output: `["a","b","z"]`
