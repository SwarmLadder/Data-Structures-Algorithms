# I05 — Consolidate closed maintenance windows

**Medium** · Sorting / intervals

## The challenge

Merge intervals [start,end] into disjoint closed intervals, sorted by start. Intervals share time when one endpoint equals another, so touching intervals must merge. Do not mutate the input.

**Constraints:** 0 <= len(intervals) <= 100000; start <= end.

**Function to implement:** `def solve(intervals):`

## Examples

1. Input arguments: `[[[1,3],[2,6],[8,10],[15,18]]]` → expected output: `[[1,6],[8,10],[15,18]]`
2. Input arguments: `[[[1,4],[4,5]]]` → expected output: `[[1,5]]`

### A. From baseline to the right data structure

Without sorting, comparing every pair of intervals repeatedly is cumbersome and slow. Sorting by start guarantees that any possible new overlap concerns the last merged interval.

### B. Invariant or recurrence and why it works

Maintain a list of disjoint, sorted merged intervals from all processed inputs. For new [a,b], if a≤the last end, extend that end to max(previous_end,b); otherwise append a new interval.

### C. Work through a real example

- Function arguments: `[[[1, 3], [2, 6], [8, 10], [15, 18]]]`
- Expected output: `[[1, 6], [8, 10], [15, 18]]`

For [[1,3],[2,6],[8,10],[15,18]], the first two merge to [1,6] because 2≤3; the remaining intervals do not overlap.

### D. Executable reference implementation

```python
"""Reference answer for I05. See the problem statement before reading.
"""
def solve(intervals):
    merged = []
    for a, b in sorted(intervals):
        if merged and a <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], b)
        else:
            merged.append([a,b])
    return merged
```

### E. Complexity derivation

O(n log n) sorting plus O(n) merge scan, O(n) output. Python sorted creates a new list, so the reference leaves the outer input list intact.

### F. Failure modes that expose memorized solutions

The course defines **closed** intervals, meaning [1,3] and [3,5] overlap. With half-open intervals the endpoint decision may be different.

### G. Transfer the technique

Variant: merge half-open time slots, distinguishing true overlap from mere contact at the same endpoint.
