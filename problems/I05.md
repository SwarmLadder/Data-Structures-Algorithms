# I05 — Consolidate closed maintenance windows

**Medium** · Sorting / intervals

## The challenge

Merge intervals [start,end] into disjoint closed intervals, sorted by start. Intervals share time when one endpoint equals another, so touching intervals must merge. Do not mutate the input.

**Constraints:** 0 <= len(intervals) <= 100000; start <= end.

**Function to implement:** `def solve(intervals):`

## Examples

1. Input arguments: `[[[1,3],[2,6],[8,10],[15,18]]]` → expected output: `[[1,6],[8,10],[15,18]]`
2. Input arguments: `[[[1,4],[4,5]]]` → expected output: `[[1,5]]`
