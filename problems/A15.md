# A15 — Enumerate combinations of reusable package sizes

**Medium** · Backtracking / combinations

## The challenge

Given distinct positive sizes and target, return every unique nondecreasing list of sizes that sums to target. Each size may be used any number of times. Sort the list of combinations lexicographically. Return [[]] for target=0.

**Constraints:** 1 <= len(sizes) <= 15; 1 <= sizes[i] <= 100; 0 <= target <= 35.

**Function to implement:** `def solve(sizes, target):`

## Examples

1. Input arguments: `[[2,3,6,7],7]` → expected output: `[[2,2,3],[7]]`
2. Input arguments: `[[2,3,5],8]` → expected output: `[[2,2,2,2],[2,3,3],[3,5]]`

### A. From baseline to the right data structure

Enumerating ordered sequences overcounts combinations such as [2,3] and [3,2]. Sort available positive sizes and carry a nondecreasing start index through recursion.

### B. Invariant or recurrence and why it works

At each depth, future choices have index ≥start; reusing the same index permits unlimited copies, but no smaller index can follow, so each multiset combination is generated once. Remaining target strictly decreases for positive sizes.

### C. Work through a real example

- Function arguments: `[[2, 3, 6, 7], 7]`
- Expected output: `[[2, 2, 3], [7]]`

With sizes [2,3,6,7] and target 7, outputs include [2,2,3] and [7], but never a separate [3,2,2] permutation.

### D. Executable reference implementation

```python
"""Reference answer for A15. See the problem statement before reading.
"""
def solve(sizes, target):
    values = sorted(sizes)
    result = []
    def dfs(start, remaining, path):
        if remaining == 0:
            result.append(path[:]); return
        for i in range(start,len(values)):
            size = values[i]
            if size > remaining: break
            path.append(size)
            dfs(i,remaining-size,path)
            path.pop()
    dfs(0,target,[])
    return result
```

### E. Complexity derivation

Exponential worst-case exploration and output-dependent time; recursion depth O(target/min_size) for positive sizes, plus O(total emitted elements) output memory.

### F. Failure modes that expose memorized solutions

Sizes must be positive or pruning `size>remaining` and termination assumptions break. If candidate sizes contain duplicates, deduplicate upfront when combinations are by value.
