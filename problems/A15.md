# A15 — Enumerate combinations of reusable package sizes

**Medium** · Backtracking / combinations

## The challenge

Given distinct positive sizes and target, return every unique nondecreasing list of sizes that sums to target. Each size may be used any number of times. Sort the list of combinations lexicographically. Return [[]] for target=0.

**Constraints:** 1 <= len(sizes) <= 15; 1 <= sizes[i] <= 100; 0 <= target <= 35.

**Function to implement:** `def solve(sizes, target):`

## Examples

1. Input arguments: `[[2,3,6,7],7]` → expected output: `[[2,2,3],[7]]`
2. Input arguments: `[[2,3,5],8]` → expected output: `[[2,2,2,2],[2,3,3],[3,5]]`
