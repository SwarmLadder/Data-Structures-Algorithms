# B05 — First alert timestamp at or above threshold

**Easy** · Binary search

## The challenge

Given a nondecreasing integer array, return the first index where nums[index] >= threshold; return len(nums) when all values are smaller. Do not linearly scan.

**Constraints:** 0 <= len(nums) <= 100000; duplicates allowed.

**Function to implement:** `def solve(nums, threshold):`

## Examples

1. Input arguments: `[[1,2,2,2,5],2]` → expected output: `1`
2. Input arguments: `[[1,3,5],2]` → expected output: `1`
