# B05 — First alert timestamp at or above threshold

**Easy** · Binary search

## The challenge

Given a nondecreasing integer array, return the first index where nums[index] >= threshold; return len(nums) when all values are smaller. Do not linearly scan.

**Constraints:** 0 <= len(nums) <= 100000; duplicates allowed.

**Function to implement:** `def solve(nums, threshold):`

## Examples

1. Input arguments: `[[1,2,2,2,5],2]` → expected output: `1`
2. Input arguments: `[[1,3,5],2]` → expected output: `1`

### A. From baseline to the right data structure

Linear search locates the boundary in O(n). Because nums is nondecreasing, the predicate nums[i]≥threshold switches from false to true at most once, enabling binary search.

### B. Invariant or recurrence and why it works

Maintain [lo,hi): all indexes strictly before lo are too small; indexes from hi onward have already been established as large enough or are past the array. `mid` either moves lo to mid+1 or hi to mid. Width strictly decreases.

### C. Work through a real example

- Function arguments: `[[1, 2, 2, 2, 5], 2]`
- Expected output: `1`

In [1,2,2,2,5] for threshold 2: mid=2 has 2 so hi=2; mid=1 has 2 so hi=1; mid=0 has 1 so lo=1. Return first valid index 1, not an arbitrary index of 2.

### D. Executable reference implementation

```python
"""Reference answer for B05. See the problem statement before reading.
"""
def solve(nums, threshold):
    lo, hi = 0, len(nums)
    while lo < hi:
        mid = (lo + hi) // 2
        if nums[mid] < threshold:
            lo = mid + 1
        else:
            hi = mid
    return lo
```

### E. Complexity derivation

O(log(n+1)) comparisons and O(1) extra space. Empty array returns 0; when all elements are smaller, return n.

### F. Failure modes that expose memorized solutions

A common binary search returns immediately on equality and therefore picks an arbitrary duplicate. Inclusive hi=n−1 and half-open hi=n require different update rules.

### G. Transfer the technique

Variant: implement upper bound, the first index with nums[i]>threshold, then derive the number of equal values from the two boundaries.
