# B12 — Square ordered temperature offsets

**Easy** · Two pointers

## The challenge

Given a nondecreasing array, return the squares in nondecreasing order. Do not call a sorting function on the output.

**Constraints:** 0 <= len(nums) <= 100000; -10000 <= nums[i] <= 10000.

**Function to implement:** `def solve(nums):`

## Examples

1. Input arguments: `[[-4,-1,0,3,10]]` → expected output: `[0,1,9,16,100]`
2. Input arguments: `[[-7,-3,2,3,11]]` → expected output: `[4,9,9,49,121]`

### A. From baseline to the right data structure

Squaring a sorted array destroys monotone order when negatives exist. However, the greatest **absolute value** must be at one of the two ends.

### B. Invariant or recurrence and why it works

Fill the output from right to left. At every step the larger remaining magnitude produces the largest remaining square. Choosing it and shrinking that endpoint preserves this invariant until the result is complete.

### C. Work through a real example

- Function arguments: `[[-4, -1, 0, 3, 10]]`
- Expected output: `[0, 1, 9, 16, 100]`

For [-4,-1,0,3,10], compare |−4| with |10| and place 100 at the end, then compare |−4| with |3| and place 16, then 9,1,0: [0,1,9,16,100].

### D. Executable reference implementation

```python
"""Reference answer for B12. See the problem statement before reading.
"""
def solve(nums):
    result = [0] * len(nums)
    left, right = 0, len(nums) - 1
    for i in range(len(nums) - 1, -1, -1):
        if abs(nums[left]) >= abs(nums[right]):
            result[i] = nums[left] ** 2
            left += 1
        else:
            result[i] = nums[right] ** 2
            right -= 1
    return result
```

### E. Complexity derivation

O(n) time and O(n) output memory; left/right indexes use O(1) auxiliary space beyond output. Squaring and sorting would take O(n log n).

### F. Failure modes that expose memorized solutions

Do not assume the most negative number has the smallest square; do not fill the output from left to right while selecting the largest magnitude.

### G. Transfer the technique

Variant: produce squares **in place** when reordering is allowed, and explain why doing so safely with O(1) memory is less trivial.
