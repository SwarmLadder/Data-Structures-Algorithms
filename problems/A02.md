# A02 — Deterministic shortest route across dependencies

**Medium** · Breadth-first search

## The challenge

Given n directed vertices 0..n-1, edges [u,v], start and target, return the lexicographically smallest shortest path as a list of vertex IDs. If no route exists return []; start==target returns [start].

**Constraints:** 1 <= n <= 100000; 0 <= number of edges <= 200000; valid vertex IDs.

**Function to implement:** `def solve(n, edges, start, target):`

## Examples

1. Input arguments: `[5,[[0,1],[0,2],[1,4],[2,4]],0,4]` → expected output: `[0,1,4]`
2. Input arguments: `[4,[[0,1],[1,2]],0,3]` → expected output: `[]`
