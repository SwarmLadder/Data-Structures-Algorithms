# A02 — Deterministic shortest route across dependencies

**Medium** · Breadth-first search

## The challenge

Given n directed vertices 0..n-1, edges [u,v], start and target, return the lexicographically smallest shortest path as a list of vertex IDs. If no route exists return []; start==target returns [start].

**Constraints:** 1 <= n <= 100000; 0 <= number of edges <= 200000; valid vertex IDs.

**Function to implement:** `def solve(n, edges, start, target):`

## Examples

2. Input arguments: `[4,[[0,1],[1,2]],0,3]` → expected output: `[]`

### A. From baseline to the right data structure

Breadth-first search discovers minimum-edge-count routes in an unweighted directed graph. Record a parent on first discovery and follow parents backward from target.

### B. Invariant or recurrence and why it works

BFS visits vertices in nondecreasing distance. Sorting each outgoing adjacency list imposes a deterministic neighbor order, so first discovered parents yield the specified tie behavior among shortest paths.

### C. Work through a real example

- Function arguments: `[5, [[0, 1], [0, 2], [1, 4], [2, 4]], 0, 4]`
- Expected output: `[0, 1, 4]`

In a graph with 0→1,0→2,1→3,2→3, BFS starts at 0, enqueues 1 then 2, discovers 3 first through 1 and reconstructs [0,1,3]. If target is unreachable return [].

### D. Executable reference implementation

```python
"""Reference answer for A02. See the problem statement before reading.
"""
def solve(n, edges, start, target):
    from collections import deque
    graph = [[] for _ in range(n)]
    for a,b in edges:
        graph[a].append(b)
    for values in graph:
        values.sort()
    parent = {start: None}
    queue = deque([start])
    while queue:
        current = queue.popleft()
        if current == target:
            break
        for nxt in graph[current]:
            if nxt not in parent:
                parent[nxt] = current
                queue.append(nxt)
    if target not in parent:
        return []
    path = []
    node = target
    while node is not None:
        path.append(node)
        node = parent[node]
    return path[::-1]
```

### E. Complexity derivation

Adjacency construction O(V+E); sorting neighbor lists up to O(E log E); BFS O(V+E); parent/queue memory O(V+E) including graph.

### F. Failure modes that expose memorized solutions

Undirected edges must be inserted both ways, but this problem uses directed edges. Mark vertices visited at enqueue, not dequeue, or repeated edges may cause duplicate queue entries.
