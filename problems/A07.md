# A07 — Fewest batch sizes to meet a target

**Medium** · Dynamic programming

## The challenge

Given distinct positive batch sizes and a nonnegative target, return the minimum number of batches that exactly sum to target, allowing unlimited use of each size. Return -1 if impossible.

**Constraints:** 1 <= len(sizes) <= 100; 1 <= sizes[i] <= 10000; 0 <= target <= 10000.

**Function to implement:** `def solve(sizes, target):`

## Examples

1. Input arguments: `[[1,2,5],11]` → expected output: `3`
2. Input arguments: `[[2],3]` → expected output: `-1`

### A. From baseline to the right data structure

Greedy choosing the largest reusable size can fail: with sizes [1,3,4], target 6, greedy uses 4+1+1 (3) while 3+3 uses 2. Use minimum-count DP over totals.

### B. Invariant or recurrence and why it works

dp[t] is the minimum number of items summing to t. The final item has size s, leaving t−s, so dp[t]=min(dp[t−s]+1) across valid s. Base dp[0]=0; unreachable values start above any possible valid count.

### C. Work through a real example

- Function arguments: `[[1, 2, 5], 11]`
- Expected output: `3`

For sizes [1,3,4], dp[3]=1, dp[4]=1, dp[6] considers 3+3 and returns 2. If no sizes can reach target, return −1 instead of a sentinel.

### D. Executable reference implementation

```python
"""Reference answer for A07. See the problem statement before reading.
"""
def solve(sizes, target):
    limit = target + 1
    dp = [limit] * (target + 1)
    dp[0] = 0
    for total in range(1, target + 1):
        for size in sizes:
            if size <= total:
                dp[total] = min(dp[total], dp[total-size]+1)
    return -1 if dp[target] == limit else dp[target]
```

### E. Complexity derivation

O(target·number_of_sizes) time and O(target) DP memory. Reusable sizes require strictly positive values to avoid invalid self-references.

### F. Failure modes that expose memorized solutions

Loop over every candidate size, including s=target. Starting dp[0] as infinity makes every positive state unreachable; a zero-size candidate can cause meaningless recurrence.
