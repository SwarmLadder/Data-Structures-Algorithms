# B09 — Most frequent error labels

**Medium** · Counting / sorting

## The challenge

Return the k most frequent distinct lowercase labels ordered by descending frequency, breaking ties alphabetically. k is valid.

**Constraints:** 1 <= len(labels) <= 100000; 1 <= k <= number of distinct labels.

**Function to implement:** `def solve(labels, k):`

## Examples

1. Input arguments: `[["timeout","disk","timeout","cpu","disk","timeout"],2]` → expected output: `["timeout","disk"]`
2. Input arguments: `[["b","a","b","a"],1]` → expected output: `["a"]`

### A. From baseline to the right data structure

For top-frequency labels, use a count map to avoid rescanning all labels for every candidate. Sort distinct labels by descending frequency and ascending alphabetic label for ties.

### B. Invariant or recurrence and why it works

After counting, counts[x] is exact. Sorting keys by (-counts[x],x) imposes the complete required order, so the first k keys are the requested winners. Sorting only by frequency leaves ties underspecified.

### C. Work through a real example

- Function arguments: `[["timeout", "disk", "timeout", "cpu", "disk", "timeout"], 2]`
- Expected output: `["timeout", "disk"]`

For [error,warn,error,info,warn] with k=2, error and warn each occur twice, so alphabetical tie order returns [error,warn]. If k exceeds distinct labels, return all distinct labels.

### D. Executable reference implementation

```python
"""Reference answer for B09. See the problem statement before reading.
"""
def solve(labels, k):
    from collections import Counter
    counts = Counter(labels)
    return sorted(counts, key=lambda x: (-counts[x], x))[:k]
```

### E. Complexity derivation

If n input labels and d distinct labels, expected O(n) counting and O(d log d) sort comparisons, plus string comparison/key costs; O(d) counts/sorted keys.

### F. Failure modes that expose memorized solutions

A heap can reduce sorting work when k≪d, but tie comparison must be part of the heap key. Do not count case-insensitive labels unless requested.

### G. Transfer the technique

Variant: return labels with their counts and support streaming updates; discuss why maintaining an exact top-k under deletions is harder.
