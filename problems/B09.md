# B09 — Most frequent error labels

**Medium** · Counting / sorting

## The challenge

Return the k most frequent distinct lowercase labels ordered by descending frequency, breaking ties alphabetically. k is valid.

**Constraints:** 1 <= len(labels) <= 100000; 1 <= k <= number of distinct labels.

**Function to implement:** `def solve(labels, k):`

## Examples

1. Input arguments: `[["timeout","disk","timeout","cpu","disk","timeout"],2]` → expected output: `["timeout","disk"]`
2. Input arguments: `[["b","a","b","a"],1]` → expected output: `["a"]`
