# I03 — Count consecutive batches matching a net total

**Medium** · Prefix sum frequency

## The challenge

Return the number of nonempty contiguous subarrays whose sum equals target. Values can be negative or zero, so a standard nonnegative sliding window is not sufficient.

**Constraints:** 0 <= len(nums) <= 100000; signed integer values.

**Function to implement:** `def solve(nums, target):`

## Examples

1. Input arguments: `[[1,1,1],2]` → expected output: `2`
2. Input arguments: `[[1,2,3],3]` → expected output: `2`
