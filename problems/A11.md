# A11 — Choose nonrepeatable upgrades under a budget

**Medium** · 0/1 knapsack

## The challenge

Each upgrade is [cost,value]. Select any subset, using an upgrade at most once, with total cost <= budget. Return the maximum achievable total value. Empty selection is allowed.

**Constraints:** 0 <= len(upgrades) <= 200; 0 <= budget <= 10000; costs >= 1, values >= 0.

**Function to implement:** `def solve(upgrades, budget):`

## Examples

1. Input arguments: `[[[1,1],[3,4],[4,5],[5,7]],7]` → expected output: `9`
2. Input arguments: `[[[2,3],[3,4]],1]` → expected output: `0`

### A. From baseline to the right data structure

Enumerating all subsets takes O(2^n). A 0/1 knapsack DP records best value achievable within each budget, processing each upgrade once.

### B. Invariant or recurrence and why it works

After processing i items, dp[c] represents maximum value using only the first i items and budget c. Descending capacities ensure dp[c−cost] still refers to **previous items**, prohibiting reuse of the current item.

### C. Work through a real example

- Function arguments: `[[[1, 1], [3, 4], [4, 5], [5, 7]], 7]`
- Expected output: `9`

For one item (cost 2,value 3) and budget 4, correct answer is 3. Ascending capacity would let that item update dp[2]=3 then dp[4]=6 in the same iteration, incorrectly using it twice.

### D. Executable reference implementation

```python
"""Reference answer for A11. See the problem statement before reading.
"""
def solve(upgrades, budget):
    dp = [0] * (budget + 1)
    for cost,value in upgrades:
        for cap in range(budget,cost-1,-1):
            dp[cap] = max(dp[cap], dp[cap-cost]+value)
    return dp[budget]
```

### E. Complexity derivation

O(n·budget) time and O(budget) extra space, where n is number of upgrades. This is pseudo-polynomial in numeric budget rather than polynomial in its bit-length.

### F. Failure modes that expose memorized solutions

Do not use ascending capacity for 0/1 items. Confirm zero-value, zero-cost and empty-upgrade behavior from constraints before indexing.
