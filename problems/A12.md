# A12 — Maximum path sum across a binary tree

**Hard** · Tree DFS / postorder

## The challenge

For a nonempty heap-indexed tree (root 0; children 2i+1 and 2i+2; null means missing), return the largest sum of any path that follows parent-child edges, without repeating nodes. A path may start and end at any reachable nodes.

**Constraints:** 1 <= len(tree) <= 100000; root is an integer; node values may be negative.

**Function to implement:** `def solve(tree):`

## Examples

1. Input arguments: `[[1,2,3]]` → expected output: `6`
2. Input arguments: `[[-10,9,20,null,null,15,7]]` → expected output: `42`

### A. From baseline to the right data structure

The maximum path can start/end anywhere in the tree and need not include the root. Postorder processing computes the best downward contribution from each child.

### B. Invariant or recurrence and why it works

For each node, gain[node]=node_value+max(0,left_gain,right_gain) is the best **one-arm** path to send upward. A full path through the node can take two arms, so candidate=node_value+max(0,left_gain)+max(0,right_gain) updates global best.

### C. Work through a real example

- Function arguments: `[[1, 2, 3]]`
- Expected output: `6`

For root −10 with children 9 and 20, and 20’s children 15,7, the best path is 15→20→7, sum 42, even though it excludes the root.

### D. Executable reference implementation

```python
"""Reference answer for A12. See the problem statement before reading.
"""
def solve(tree):
    stack = [(0,False)]
    gain = {}
    best = float('-inf')
    while stack:
        i,visited = stack.pop()
        if i >= len(tree) or tree[i] is None:
            continue
        if not visited:
            stack.append((i,True))
            stack.append((2*i+1,False))
            stack.append((2*i+2,False))
        else:
            left = max(0,gain.get(2*i+1,0))
            right = max(0,gain.get(2*i+2,0))
            best = max(best,tree[i]+left+right)
            gain[i] = tree[i] + max(left,right)
    return int(best)
```

### E. Complexity derivation

O(n) time and O(n) auxiliary space in this explicit-stack/reference implementation (visited flags and per-index gains). An ordinary recursive version uses O(h) stack.

### F. Failure modes that expose memorized solutions

Initialize global best to negative infinity, not zero, or an all-negative tree will wrongly report an empty path of value 0. Do not send both child gains upward: that would branch the path.

### G. Transfer the technique

Variant: return node indexes on the best path, tracking endpoints and reconstructing both arms.
