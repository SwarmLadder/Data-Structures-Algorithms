# I14 — Return tree nodes by depth

**Medium** · Breadth-first search

## The challenge

A tree uses heap-style indexes (left=2*i+1, right=2*i+2), with null for absent nodes. Ignore descendants of missing nodes. Return values grouped by depth, left to right. Return [] when root is missing.

**Constraints:** 0 <= len(tree) <= 100000; values are integers or null.

**Function to implement:** `def solve(tree):`

## Examples

1. Input arguments: `[[3,9,20,null,null,15,7]]` → expected output: `[[3],[9,20],[15,7]]`
2. Input arguments: `[[1]]` → expected output: `[[1]]`
