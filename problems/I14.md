# I14 — Return tree nodes by depth

**Medium** · Breadth-first search

## The challenge

A tree uses heap-style indexes (left=2*i+1, right=2*i+2), with null for absent nodes. Ignore descendants of missing nodes. Return values grouped by depth, left to right. Return [] when root is missing.

**Constraints:** 0 <= len(tree) <= 100000; values are integers or null.

**Function to implement:** `def solve(tree):`

## Examples

1. Input arguments: `[[3,9,20,null,null,15,7]]` → expected output: `[[3],[9,20],[15,7]]`
2. Input arguments: `[[1]]` → expected output: `[[1]]`

### A. From baseline to the right data structure

A depth-first traversal can collect levels if it tracks depth, but BFS naturally visits nodes by nondecreasing depth and thus directly groups them.

### B. Invariant or recurrence and why it works

Store (array index, depth) pairs in a deque. When a valid node is popped, extend the answer with a list for its depth if needed, append the value, and enqueue existing child positions for the next level.

### C. Work through a real example

- Function arguments: `[[3, 9, 20, null, null, 15, 7]]`
- Expected output: `[[3], [9, 20], [15, 7]]`

For tree [3,9,20,None,None,15,7] using heap indexing: level 0 is [3], level 1 [9,20], level 2 [15,7]. Null positions are not emitted.

### D. Executable reference implementation

```python
"""Reference answer for I14. See the problem statement before reading.
"""
def solve(tree):
    from collections import deque
    if not tree or tree[0] is None:
        return []
    queue = deque([(0,0)])
    answer = []
    while queue:
        index, depth = queue.popleft()
        if index >= len(tree) or tree[index] is None:
            continue
        if len(answer) == depth:
            answer.append([])
        answer[depth].append(tree[index])
        queue.append((index*2+1, depth+1))
        queue.append((index*2+2, depth+1))
    return answer
```

### E. Complexity derivation

O(n) in the number of array positions examined (bounded by encoded array length), with O(n) queue/output memory.

### F. Failure modes that expose memorized solutions

Do not treat None as a real node or enqueue its descendants as valid children. The array encoding differs from compact BFS serialization.

### G. Transfer the technique

Variant: return right-to-left values per level by reversing individual layers while preserving BFS traversal complexity.
