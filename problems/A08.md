# A08 — Segment a service name into allowed tokens

**Medium** · Dynamic programming / strings

## The challenge

Return True if text can be split into one or more words from dictionary, allowing reuse. The empty text is segmentable without using any words. Dictionary words are nonempty and distinct.

**Constraints:** 0 <= len(text) <= 2000; up to 1000 dictionary words; total dictionary length <= 20000.

**Function to implement:** `def solve(text, dictionary):`

### A. From baseline to the right data structure

Trying every split of a string recursively repeats prefix/suffix states. DP records whether each text prefix can be segmented into allowed dictionary words.

### B. Invariant or recurrence and why it works

dp[end] is true iff text[:end] can be split. A valid final word has length L and equals text[end−L:end], while dp[end−L] must already be true. Base dp[0]=True covers the empty prefix.

### C. Work through a real example

- Function arguments: `["leetcode", ["leet", "code"]]`
- Expected output: `true`

For text=leetcode and dictionary [leet,code], dp[4] is true after leet, and dp[8] becomes true using code. With dictionary [leet,co], the full text remains unreachable.

### D. Executable reference implementation

```python
"""Reference answer for A08. See the problem statement before reading.
"""
def solve(text, dictionary):
    words = set(dictionary)
    lengths = {len(w) for w in words}
    dp = [False] * (len(text) + 1)
    dp[0] = True
    for end in range(1,len(text)+1):
        dp[end] = any(end >= length and dp[end-length] and text[end-length:end] in words for length in lengths)
    return dp[-1]
```

### E. Complexity derivation

O(n·D·L) conservative worst-case when checking D distinct word lengths and slicing/lookup of substrings up to length L; O(n+dictionary_storage) DP and set memory.

### F. Failure modes that expose memorized solutions

Trimming dictionary to a set avoids duplicate lookup effort, but a negative match must not be accepted solely because its length is available. Empty text is segmentable.

### G. Transfer the technique

Variant: count all segmentations rather than returning a boolean, and discuss potentially exponential output versus polynomial counting DP.
