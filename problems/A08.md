# A08 — Segment a service name into allowed tokens

**Medium** · Dynamic programming / strings

## The challenge

Return True if text can be split into one or more words from dictionary, allowing reuse. The empty text is segmentable without using any words. Dictionary words are nonempty and distinct.

**Constraints:** 0 <= len(text) <= 2000; up to 1000 dictionary words; total dictionary length <= 20000.

**Function to implement:** `def solve(text, dictionary):`

## Examples

1. Input arguments: `["leetcode",["leet","code"]]` → expected output: `true`
2. Input arguments: `["catsandog",["cats","dog","sand","and","cat"]]` → expected output: `false`
