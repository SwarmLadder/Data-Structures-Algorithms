# B02 — Group request tokens by letter composition

**Medium** · Hash map / strings

## The challenge

Group strings that are anagrams of one another. Within each group sort words alphabetically, then sort groups by their first word. Preserve duplicate words. The empty string is valid.

**Constraints:** 0 <= len(words) <= 20000; words contain lowercase a-z.

**Function to implement:** `def solve(words):`

## Examples

1. Input arguments: `[["eat","tea","tan","ate","nat","bat"]]` → expected output: `[["ate","eat","tea"],["bat"],["nat","tan"]]`
2. Input arguments: `[["","","a"]]` → expected output: `[["",""],["a"]]`

### A. From baseline to the right data structure

A brute-force grouping approach repeatedly compares pairs of words by sorting or counting characters. Hash each word by a canonical signature so anagrams enter the same bucket.

### B. Invariant or recurrence and why it works

The dictionary key is sorted characters, which is identical exactly for anagrams over the stated alphabet. Each word is appended once. Sort words inside every group, then sort the groups by their first member to meet the deterministic output contract.

### C. Work through a real example

- Function arguments: `[["eat", "tea", "tan", "ate", "nat", "bat"]]`
- Expected output: `[["ate", "eat", "tea"], ["bat"], ["nat", "tan"]]`

For [eat,tea,tan,ate,nat,bat], canonical key aet collects eat/tea/ate; ant collects tan/nat. After sorting, output groups [ate,eat,tea], [bat], [nat,tan]. Duplicates are retained, not deduplicated.

### D. Executable reference implementation

```python
"""Reference answer for B02. See the problem statement before reading.
"""
def solve(words):
    from collections import defaultdict
    groups = defaultdict(list)
    for word in words:
        groups[''.join(sorted(word))].append(word)
    return sorted((sorted(g) for g in groups.values()), key=lambda g: g[0])
```

### E. Complexity derivation

For n words of max length k, forming signatures costs O(n·k log k), group sorting at most O(n log n) comparisons of strings, and memory O(total input characters) for keys/groups; string-comparison costs also matter.

### F. Failure modes that expose memorized solutions

Using `set(words)` discards valid duplicates. Returning unsorted dictionary buckets does not guarantee required group order. Empty string has a valid empty signature.
