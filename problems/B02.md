# B02 — Group request tokens by letter composition

**Medium** · Hash map / strings

## The challenge

Group strings that are anagrams of one another. Within each group sort words alphabetically, then sort groups by their first word. Preserve duplicate words. The empty string is valid.

**Constraints:** 0 <= len(words) <= 20000; words contain lowercase a-z.

**Function to implement:** `def solve(words):`

## Examples

1. Input arguments: `[["eat","tea","tan","ate","nat","bat"]]` → expected output: `[["ate","eat","tea"],["bat"],["nat","tan"]]`
2. Input arguments: `[["","","a"]]` → expected output: `[["",""],["a"]]`
