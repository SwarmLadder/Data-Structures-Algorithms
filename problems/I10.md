# I10 — Locate a target in rotated configuration IDs

**Medium** · Binary search / rotation

## The challenge

nums is a strictly increasing integer array rotated at an unknown pivot. Return the index of target, or -1 if missing. Do not scan linearly.

**Constraints:** 0 <= len(nums) <= 100000; no duplicate values.

**Function to implement:** `def solve(nums, target):`

## Examples

1. Input arguments: `[[4,5,6,7,0,1,2],0]` → expected output: `4`
2. Input arguments: `[[4,5,6,7,0,1,2],3]` → expected output: `-1`
