# I13 — Validate a search tree from an array

**Medium** · Binary search tree / recursion

## The challenge

A tree is represented as a binary heap-style array: root at 0, children of index i at 2*i+1 and 2*i+2; null denotes absent nodes, and descendants of null nodes are ignored. Return whether all reachable nodes satisfy strict BST ordering (no duplicates). An empty tree is valid.

**Constraints:** 0 <= len(tree) <= 100000; values are integers or null.

**Function to implement:** `def solve(tree):`

## Examples

1. Input arguments: `[[2,1,3]]` → expected output: `true`
2. Input arguments: `[[5,1,4,null,null,3,6]]` → expected output: `false`

### A. From baseline to the right data structure

Checking only immediate child values is insufficient to validate an entire BST. Each node inherits lower/upper limits from all ancestors.

### B. Invariant or recurrence and why it works

When visiting a node with permitted interval (lo,hi), require lo<value<hi; left child gets (lo,value), right gets (value,hi). This ensures no grandchild violates an ancestor boundary.

### C. Work through a real example

- Function arguments: `[[2, 1, 3]]`
- Expected output: `true`

For root 10, left child 5, left-right child 12: local checks at 5 pass (5<12), but 12 violates the root upper bound 10. Range checking rejects it.

### D. Executable reference implementation

```python
"""Reference answer for I13. See the problem statement before reading.
"""
def solve(tree):
    if not tree or tree[0] is None:
        return True
    stack = [(0, None, None)]
    while stack:
        i, low, high = stack.pop()
        if i >= len(tree) or tree[i] is None:
            continue
        x = tree[i]
        if (low is not None and x <= low) or (high is not None and x >= high):
            return False
        stack.append((2 * i + 1, low, x))
        stack.append((2 * i + 2, x, high))
    return True
```

### E. Complexity derivation

O(n) worst-case time to inspect nodes, O(h) recursive stack where h is tree height. The encoded array shape determines reachable positions and potential sparsity.

### F. Failure modes that expose memorized solutions

The challenge specifies a heap-indexed binary array with None placeholders; do not parse it as compact BFS serialization. Strict inequality rejects duplicates when they are forbidden.
