# A04 — Minimum delivery delay through a weighted network

**Medium** · Dijkstra / min heap

## The challenge

Given n vertices and directed edges [u,v,weight] with nonnegative weights, return minimum distances from source to all vertices. Use -1 for unreachable vertices. Repeated edges are valid.

**Constraints:** 1 <= n <= 100000; 0 <= edges <= 200000; 0 <= weight <= 10**9.

**Function to implement:** `def solve(n, edges, source):`

## Examples

1. Input arguments: `[5,[[0,1,2],[0,2,5],[1,2,1],[2,3,3]],0]` → expected output: `[0,2,3,6,-1]`
2. Input arguments: `[3,[[0,1,1]],0]` → expected output: `[0,1,-1]`

### A. From baseline to the right data structure

BFS counts edges, not weighted cost. Dijkstra selects the lowest tentative cost in a heap and relaxes all nonnegative outgoing edges.

### B. Invariant or recurrence and why it works

The distance array is the best discovered source-to-vertex cost; with nonnegative edges, popping its current minimum is safe to finalize. Outdated heap entries are skipped when their stored cost differs from dist[u].

### C. Work through a real example

- Function arguments: `[5, [[0, 1, 2], [0, 2, 5], [1, 2, 1], [2, 3, 3]], 0]`
- Expected output: `[0, 2, 3, 6, -1]`

For 0→1 cost 5, 0→2 cost 1, 2→1 cost 1: first propose dist[1]=5, then improve to 2 via vertex 2. When (5,1) is popped it is stale and ignored.

### D. Executable reference implementation

```python
"""Reference answer for A04. See the problem statement before reading.
"""
def solve(n, edges, source):
    import heapq
    graph = [[] for _ in range(n)]
    for u,v,w in edges:
        graph[u].append((v,w))
    dist = [float('inf')] * n
    dist[source] = 0
    heap = [(0,source)]
    while heap:
        cost,u = heapq.heappop(heap)
        if cost != dist[u]:
            continue
        for v,w in graph[u]:
            new_cost = cost + w
            if new_cost < dist[v]:
                dist[v] = new_cost
                heapq.heappush(heap,(new_cost,v))
    return [-1 if x == float('inf') else int(x) for x in dist]
```

### E. Complexity derivation

Graph O(V+E) memory; lazy heap Dijkstra O(E log(E+1)) time on conventional simple input bounds, often stated O((V+E)log V), plus O(E) heap worst case.

### F. Failure modes that expose memorized solutions

Negative edge weights invalidate the safe-finalization proof; use Bellman–Ford instead when negatives are allowed. Unreachable vertices map to -1, not zero.
