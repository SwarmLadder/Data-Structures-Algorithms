# B11 — Check a one-to-one masking map

**Easy** · Hash map / strings

## The challenge

Return True if every character of source maps consistently to exactly one character of masked and no two source characters share the same mapped character. Lengths must match.

**Constraints:** 0 <= string lengths <= 100000; ASCII strings.

**Function to implement:** `def solve(source, masked):`

## Examples

1. Input arguments: `["egg","add"]` → expected output: `true`
2. Input arguments: `["foo","bar"]` → expected output: `false`

### A. From baseline to the right data structure

Checking only that each source character always maps to one target character enforces a function but not one-to-one mapping; two source symbols might map to the same output.

### B. Invariant or recurrence and why it works

Maintain both forward[source_char] and reverse[target_char] maps. Before inserting, reject any conflicting existing association. Together the maps establish injective and functional correspondence for every processed position.

### C. Work through a real example

- Function arguments: `["egg", "add"]`
- Expected output: `true`

For source=egg and masked=add, e→a, g→d twice: valid. For foo→bar, two o positions demand a and r, so reject. For ab→cc, reverse map rejects two inputs mapping to c.

### D. Executable reference implementation

```python
"""Reference answer for B11. See the problem statement before reading.
"""
def solve(source, masked):
    if len(source) != len(masked):
        return False
    forward, backward = {}, {}
    for a, b in zip(source, masked):
        if a in forward and forward[a] != b:
            return False
        if b in backward and backward[b] != a:
            return False
        forward[a] = b
        backward[b] = a
    return True
```

### E. Complexity derivation

O(n) expected time, O(min(n,alphabet)) map entries; a length mismatch is rejected before scanning.

### F. Failure modes that expose memorized solutions

Checking only one direction accepts collisions. Using `zip` without comparing lengths truncates unmatched suffixes silently. Case-sensitive symbols must remain distinct unless normalized explicitly.
