# B14 — Compact nonzero sensor values

**Easy** · Array compaction

## The challenge

Return a new array with all nonzero elements in their original relative order followed by all zeroes. Do not modify the input.

**Constraints:** 0 <= len(nums) <= 100000.

**Function to implement:** `def solve(nums):`

## Examples

1. Input arguments: `[[0,1,0,3,12]]` → expected output: `[1,3,12,0,0]`
2. Input arguments: `[[0,0,0]]` → expected output: `[0,0,0]`

### A. From baseline to the right data structure

A first-pass filter collects nonzero values in order; then append enough zeros to restore original length. The relative order of retained values is a core contract.

### B. Invariant or recurrence and why it works

The list comprehension maintains the input order among selected nonzero values. After it, appending exactly n−len(nonzero) zeros gives the correct total length and trailing zeros.

### C. Work through a real example

- Function arguments: `[[0, 1, 0, 3, 12]]`
- Expected output: `[1, 3, 12, 0, 0]`

For [0,1,0,3,12], the filtered list is [1,3,12] and the missing two slots become zeros: [1,3,12,0,0]. All-zero input stays all zeros.

### D. Executable reference implementation

```python
"""Reference answer for B14. See the problem statement before reading.
"""
def solve(nums):
    nonzero = [x for x in nums if x != 0]
    return nonzero + [0] * (len(nums) - len(nonzero))
```

### E. Complexity derivation

O(n) time and O(n) returned list space. An in-place write-pointer variant can achieve O(1) extra space, but it mutates the input.

### F. Failure modes that expose memorized solutions

Be clear whether the function must mutate or return a new list. Repeated list.remove(0) can cost O(n²) because elements shift.
