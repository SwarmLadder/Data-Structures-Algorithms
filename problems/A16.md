# A16 — Median across two sorted telemetry streams

**Hard** · Binary search / partition

## The challenge

Given two nondecreasing integer lists with at least one element total, return the numerical median of the merged list as a float. Do not merge or sort the arrays; seek O(log(min(n,m))) time.

**Constraints:** 0 <= lengths <= 100000; total length >= 1. Each input integer is between -10**9 and 10**9.

**Function to implement:** `def solve(a, b):`

## Examples

1. Input arguments: `[[1,3],[2]]` → expected output: `2.0`
2. Input arguments: `[[1,2],[3,4]]` → expected output: `2.5`
