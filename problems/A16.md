# A16 — Median across two sorted telemetry streams

**Hard** · Binary search / partition

## The challenge

Given two nondecreasing integer lists with at least one element total, return the numerical median of the merged list as a float. Do not merge or sort the arrays; seek O(log(min(n,m))) time.

**Constraints:** 0 <= lengths <= 100000; total length >= 1. Each input integer is between -10**9 and 10**9.

**Function to implement:** `def solve(a, b):`

## Examples

1. Input arguments: `[[1,3],[2]]` → expected output: `2.0`
2. Input arguments: `[[1,2],[3,4]]` → expected output: `2.5`

### A. From baseline to the right data structure

Fully merging both sorted streams gives O(m+n) time. Instead binary-search a partition position in the shorter array so the combined left half holds exactly half the elements.

### B. Invariant or recurrence and why it works

For partition i in shorter array and j=half−i in longer, valid ordering requires a_left≤b_right and b_left≤a_right. If a_left>b_right move i left; otherwise if b_left>a_right move i right.

### C. Work through a real example

- Function arguments: `[[1, 3], [2]]`
- Expected output: `2.0`

For a=[1,3], b=[2], swap to search shorter a=[2], b=[1,3]. Partition one left value from each side gives max(left)=2, the median.

### D. Executable reference implementation

```python
"""Reference answer for A16. See the problem statement before reading.
"""
def solve(a, b):
    if len(a) > len(b):
        a,b = b,a
    m,n = len(a),len(b)
    lo,hi = 0,m
    half = (m+n+1)//2
    while lo <= hi:
        i = (lo+hi)//2
        j = half-i
        al = a[i-1] if i else float('-inf')
        ar = a[i] if i<m else float('inf')
        bl = b[j-1] if j else float('-inf')
        br = b[j] if j<n else float('inf')
        if al <= br and bl <= ar:
            if (m+n)%2:
                return float(max(al,bl))
            return (max(al,bl)+min(ar,br))/2.0
        if al > br: hi = i-1
        else: lo = i+1
    raise ValueError('Arrays must be sorted')
```

### E. Complexity derivation

O(log(min(m,n)+1)) comparisons and O(1) auxiliary space. Inputs are assumed sorted and not both empty; each boundary uses ±infinity sentinels.

### F. Failure modes that expose memorized solutions

Do not binary search the longer input without adjusting j bounds. Off-by-one errors arise from choosing combined left-size `(m+n+1)//2` incorrectly for odd totals.

### G. Transfer the technique

Variant: return kth smallest element for arbitrary k using the same partition inequality; state the bounds on partition i.
