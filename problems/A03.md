# A03 — Plan jobs with deterministic prerequisites

**Medium** · Topological sort / heap

## The challenge

There are n jobs numbered 0..n-1. Each directed edge [u,v] requires u before v. Return the lexicographically smallest valid job ordering. If there is a cycle return []; no edges means ascending IDs.

**Constraints:** 0 <= n <= 100000; 0 <= number of edges <= 200000; valid IDs; duplicate edges permitted.

**Function to implement:** `def solve(n, edges):`

## Examples

1. Input arguments: `[4,[[0,2],[1,2],[2,3]]]` → expected output: `[0,1,2,3]`
2. Input arguments: `[2,[[0,1],[1,0]]]` → expected output: `[]`
