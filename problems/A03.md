# A03 — Plan jobs with deterministic prerequisites

**Medium** · Topological sort / heap

## The challenge

There are n jobs numbered 0..n-1. Each directed edge [u,v] requires u before v. Return the lexicographically smallest valid job ordering. If there is a cycle return []; no edges means ascending IDs.

**Constraints:** 0 <= n <= 100000; 0 <= number of edges <= 200000; valid IDs; duplicate edges permitted.

**Function to implement:** `def solve(n, edges):`

## Examples

1. Input arguments: `[4,[[0,2],[1,2],[2,3]]]` → expected output: `[0,1,2,3]`
2. Input arguments: `[2,[[0,1],[1,0]]]` → expected output: `[]`

### A. From baseline to the right data structure

Kahn’s topological algorithm repeatedly schedules vertices whose remaining indegree is zero. A min-heap ensures the smallest currently available task ID is chosen.

### B. Invariant or recurrence and why it works

The indegree array equals the number of unscheduled prerequisite edges. Every zero-indegree vertex is eligible; removing u decrements indegrees of its outgoing neighbors. All output edges point forward, so the order is valid.

### C. Work through a real example

- Function arguments: `[4, [[0, 2], [1, 2], [2, 3]]]`
- Expected output: `[0, 1, 2, 3]`

For n=4 and edges 0→2,1→2,2→3, ready initially contains 0 and 1, so output 0,1,2,3. Adding 3→1 creates a cycle; fewer than n vertices can be removed and result is [].

### D. Executable reference implementation

```python
"""Reference answer for A03. See the problem statement before reading.
"""
def solve(n, edges):
    import heapq
    graph = [set() for _ in range(n)]
    indegree = [0] * n
    for u, v in edges:
        if v not in graph[u]:
            graph[u].add(v); indegree[v] += 1
    ready = [i for i, degree in enumerate(indegree) if degree == 0]
    heapq.heapify(ready)
    order = []
    while ready:
        u = heapq.heappop(ready)
        order.append(u)
        for v in graph[u]:
            indegree[v] -= 1
            if indegree[v] == 0:
                heapq.heappush(ready, v)
    return order if len(order) == n else []
```

### E. Complexity derivation

Graph sets and indegree building expected O(V+E); heap operations O(V log V), edge relaxations O(E). Space O(V+E).

### F. Failure modes that expose memorized solutions

Duplicate edges are deduplicated before indegree increments. If adjacency is deduplicated but indegree is not, a node may incorrectly remain blocked forever.
