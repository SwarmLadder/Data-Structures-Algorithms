### A. From baseline to the right data structure

A naive attempt checks the frequency of each character by rescanning the full string, O(n²). First count all characters, then scan the original string once to find the first count equal to one.

### B. Invariant or recurrence and why it works

After the counting pass, `counts[c]` equals the total occurrences of c. The second pass scans in original positional order, so the first count-one character found is necessarily the leftmost valid answer.

### C. Work through a real example

- Function arguments: `["leetcode"]`
- Expected output: `0`

For leetcode, l is counted once, so its index 0 wins. For aabb every count is 2 and the scan returns −1. The empty string also returns −1.

### D. Executable reference implementation

```python
"""Reference answer for B03. See the problem statement before reading.
"""
def solve(text):
    from collections import Counter
    counts = Counter(text)
    for i, char in enumerate(text):
        if counts[char] == 1:
            return i
    return -1
```

### E. Complexity derivation

Two O(n) scans give O(n) time; extra memory is O(min(n, alphabet size)) distinct counts. Under the stated ASCII contract, alphabet space is bounded.

### F. Failure modes that expose memorized solutions

Do not return the first unique **dictionary key** without checking original indexes; dictionary behavior is not the desired ordering proof. Case-sensitive A and a are different.

### G. Transfer the technique

Variant: find the first symbol that appears **exactly twice** while preserving original-order tie breaking.
