# A01 — Count disconnected regions in a binary map

**Medium** · Grid flood fill

## The challenge

A rectangular grid of strings contains "1" for land and "0" for water. Count 4-connected land regions; diagonal contact alone does not connect. Do not mutate grid.

**Constraints:** 0 <= rows, columns <= 300; when nonempty all rows have equal length.

**Function to implement:** `def solve(grid):`

## Examples

1. Input arguments: `[["11110","11010","11000","00000"]]` → expected output: `1`
2. Input arguments: `[["11000","11000","00100","00011"]]` → expected output: `3`
