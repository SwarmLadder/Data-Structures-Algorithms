# A01 — Count disconnected regions in a binary map

**Medium** · Grid flood fill

## The challenge

A rectangular grid of strings contains "1" for land and "0" for water. Count 4-connected land regions; diagonal contact alone does not connect. Do not mutate grid.

**Constraints:** 0 <= rows, columns <= 300; when nonempty all rows have equal length.

**Function to implement:** `def solve(grid):`

## Examples

1. Input arguments: `[["11110","11010","11000","00000"]]` → expected output: `1`
2. Input arguments: `[["11000","11000","00100","00011"]]` → expected output: `3`

### A. From baseline to the right data structure

Scanning each land cell and starting a new BFS only when it is not visited counts connected components. Visiting a component prevents counting its other cells as new regions.

### B. Invariant or recurrence and why it works

The visited set holds exactly cells discovered by prior or current flood fills. When a fresh land cell is encountered, it belongs to a component not counted before; BFS reaches every orthogonally connected land cell before continuing the outer scan.

### C. Work through a real example

- Function arguments: `[["11110", "11010", "11000", "00000"]]`
- Expected output: `1`

For a map with land at (0,0),(0,1),(1,0) and isolated land at (2,2), first BFS consumes the 3-cell region; the later isolated cell starts the second BFS: answer 2.

### D. Executable reference implementation

```python
"""Reference answer for A01. See the problem statement before reading.
"""
def solve(grid):
    from collections import deque
    if not grid:
        return 0
    rows, cols = len(grid), len(grid[0])
    seen = set()
    islands = 0
    for r in range(rows):
        for c in range(cols):
            if grid[r][c] != '1' or (r,c) in seen:
                continue
            islands += 1
            seen.add((r,c))
            queue = deque([(r,c)])
            while queue:
                x,y = queue.popleft()
                for nx,ny in ((x-1,y),(x+1,y),(x,y-1),(x,y+1)):
                    if 0 <= nx < rows and 0 <= ny < cols and grid[nx][ny] == '1' and (nx,ny) not in seen:
                        seen.add((nx,ny)); queue.append((nx,ny))
    return islands
```

### E. Complexity derivation

O(rows·cols) time because every cell is checked and each land cell enqueued once; O(rows·cols) worst-case visited/queue memory.

### F. Failure modes that expose memorized solutions

Check whether diagonal touch counts as connected; the course uses up/down/left/right only. Empty grid returns zero and you must not index grid[0] before checking.
