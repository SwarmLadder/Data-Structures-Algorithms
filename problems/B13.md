# B13 — Common items across sorted inventories

**Easy** · Two pointers

## The challenge

Return the nondecreasing multiset intersection of sorted integer lists a and b. Each value should occur the minimum of its multiplicities in both lists.

**Constraints:** 0 <= len(a), len(b) <= 100000.

**Function to implement:** `def solve(a, b):`

## Examples

1. Input arguments: `[[1,2,2,3],[2,2,4]]` → expected output: `[2,2]`
2. Input arguments: `[[],[1]]` → expected output: `[]`
