# I12 — Implement an LRU response cache

**Medium** · Ordered map

## The challenge

Process operations ["put", key, value] and ["get", key] on a cache of capacity slots. Return the list of results from get operations only (value or -1 when missing). Both a successful get and a put of an existing key make that key most recently used. Capacity may be zero.

**Constraints:** 0 <= capacity <= 10000; 0 <= operations <= 100000; integer keys/values.

**Function to implement:** `def solve(capacity, operations):`

## Examples

1. Input arguments: `[2,[["put",1,1],["put",2,2],["get",1],["put",3,3],["get",2],["put",4,4],["get",1],["get",3],["get",4]]]` → expected output: `[1,-1,-1,3,4]`
2. Input arguments: `[0,[["put",1,1],["get",1]]]` → expected output: `[-1]`
