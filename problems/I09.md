# I09 — Next higher daily latency

**Medium** · Monotonic stack

## The challenge

For each day i return the number of days until a strictly higher latency occurs. Return zero if no later day is higher. Equal latencies do not count.

**Constraints:** 0 <= len(latencies) <= 100000.

**Function to implement:** `def solve(latencies):`

## Examples

1. Input arguments: `[[73,74,75,71,69,72,76,73]]` → expected output: `[1,1,4,2,1,1,0,0]`
2. Input arguments: `[[30,40,50,60]]` → expected output: `[1,1,1,0]`

### A. From baseline to the right data structure

A forward scan from every index gives O(n²). A stack of unresolved indices lets the next strictly larger value resolve all earlier smaller values on top.

### B. Invariant or recurrence and why it works

Indices on the stack have nonincreasing latencies from bottom to top. A new value greater than the top pops it and records i−j. No earlier new day could have been greater, or j would already be popped.

### C. Work through a real example

- Function arguments: `[[73, 74, 75, 71, 69, 72, 76, 73]]`
- Expected output: `[1, 1, 4, 2, 1, 1, 0, 0]`

For [73,74,75,71,69,72,76,73], the first day waits 1, the 75 waits 4 for 76, and the last 73 has no larger future value so wait is 0.

### D. Executable reference implementation

```python
"""Reference answer for I09. See the problem statement before reading.
"""
def solve(latencies):
    result = [0] * len(latencies)
    waiting = []
    for i, value in enumerate(latencies):
        while waiting and latencies[waiting[-1]] < value:
            j = waiting.pop()
            result[j] = i - j
        waiting.append(i)
    return result
```

### E. Complexity derivation

O(n) total time because each index is pushed and popped once. O(n) stack and result memory.

### F. Failure modes that expose memorized solutions

Use strict `<` for strictly higher values; equal latencies do not resolve earlier indexes. Store indexes rather than values because answer needs distances.

### G. Transfer the technique

Variant: return next **greater or equal** index by changing comparison and validating tie behavior.
