# I01 — Longest stretch without repeated characters

**Medium** · Sliding window

## The challenge

Return the maximum length of a contiguous substring with no repeated characters. Treat uppercase and lowercase as distinct.

**Constraints:** 0 <= len(text) <= 100000; ASCII characters.

**Function to implement:** `def solve(text):`

## Examples

1. Input arguments: `["abcabcbb"]` → expected output: `3`
2. Input arguments: `["bbbbb"]` → expected output: `1`

### A. From baseline to the right data structure

A quadratic baseline starts a substring at each index and grows until a duplicate occurs. A moving window and last-seen dictionary reuse information from previous starts.

### B. Invariant or recurrence and why it works

Maintain [left,right] containing no repeated characters. When the current character was last seen at or after left, move left to last+1. Never move left backward: older duplicates outside the window do not matter.

### C. Work through a real example

- Function arguments: `["abcabcbb"]`
- Expected output: `3`

For abcabcbb: the window grows abc (length 3), then seeing a at index 3 jumps left to 1; later repeats keep best at 3. For abba, final a has an old occurrence outside the window and must not move left backward.

### D. Executable reference implementation

```python
"""Reference answer for I01. See the problem statement before reading.
"""
def solve(text):
    last = {}
    start = best = 0
    for right, char in enumerate(text):
        if char in last and last[char] >= start:
            start = last[char] + 1
        last[char] = right
        best = max(best, right - start + 1)
    return best
```

### E. Complexity derivation

O(n) expected time; O(min(n, alphabet)) last-index map memory. Each right index is processed once and left only increases.

### F. Failure modes that expose memorized solutions

Do not count distinct characters alone; `abba` has two distinct letters but the longest unique substring length is 2. Forgetting `last[c] >= left` breaks the result.

### G. Transfer the technique

Variant: return start and end indexes of the earliest longest unique substring instead of its length.
