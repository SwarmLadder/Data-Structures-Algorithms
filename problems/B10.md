# B10 — Recover a missing sequence ID

**Easy** · Arithmetic invariants

## The challenge

An array holds n distinct numbers from 0 through n, missing exactly one. Return the missing number; an empty array means zero is missing.

**Constraints:** 0 <= n <= 100000.

**Function to implement:** `def solve(nums):`

## Examples

1. Input arguments: `[[3,0,1]]` → expected output: `2`
2. Input arguments: `[[0,1]]` → expected output: `2`
