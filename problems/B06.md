# B06 — Combine sorted audit offsets

**Easy** · Two pointers

## The challenge

Merge sorted integer lists a and b into one nondecreasing list. Keep all duplicates and leave both inputs unchanged.

**Constraints:** 0 <= len(a), len(b) <= 100000.

**Function to implement:** `def solve(a, b):`

2. Input arguments: `[[],[2,5]]` → expected output: `[2,5]`

### A. From baseline to the right data structure

Sorting the concatenation works but costs O((n+m)log(n+m)). Because each input is already sorted, compare its next available element and append the smaller.

### B. Invariant or recurrence and why it works

After i+j appended items, result is the sorted merge of the first i elements of a and first j of b. The next smallest unconsumed item must be at the front of one of the two remaining suffixes.

### C. Work through a real example

- Function arguments: `[[1, 2, 4], [1, 3, 4]]`
- Expected output: `[1, 1, 2, 3, 4, 4]`

For a=[1,2,4] and b=[1,3,4], choose a[0]=1, then b[0]=1, then 2,3,4,4. Equal values are kept; both input lists stay untouched.

### D. Executable reference implementation

```python
"""Reference answer for B06. See the problem statement before reading.
"""
def solve(a, b):
    i = j = 0
    result = []
    while i < len(a) and j < len(b):
        if a[i] <= b[j]:
            result.append(a[i]); i += 1
        else:
            result.append(b[j]); j += 1
    return result + a[i:] + b[j:]
```

### E. Complexity derivation

O(n+m) time. O(n+m) returned output space; additional pointers are O(1) beyond the required output.

### F. Failure modes that expose memorized solutions

Do not drop equal elements or mutate the inputs. The remaining suffix can be appended in bulk once one side is exhausted; avoid reading past its end.

### G. Transfer the technique

Variant: merge into preallocated capacity of the first list **in place** by filling backward; justify O(1) additional storage.
