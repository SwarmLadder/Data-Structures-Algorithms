# A10 — Minimum edits between configuration keys

**Medium** · Dynamic programming / edit distance

## The challenge

Return the minimum number of single-character insertions, deletions and replacements needed to transform source into target. Every operation costs 1.

**Constraints:** 0 <= len(source), len(target) <= 1000; lowercase strings.

**Function to implement:** `def solve(source, target):`

## Examples

1. Input arguments: `["horse","ros"]` → expected output: `3`
2. Input arguments: `["intention","execution"]` → expected output: `5`

### A. From baseline to the right data structure

Pure recursive exploration branches over insert/delete/replace and repeats the same prefix pairs. Edit-distance DP caches the optimal operation count for prefixes.

### B. Invariant or recurrence and why it works

dp[i][j] is minimum cost transforming first i source characters into first j target characters. The last operation is deletion (up), insertion (left), or replacement/match (diagonal); minimizing across these is exhaustive.

### C. Work through a real example

- Function arguments: `["horse", "ros"]`
- Expected output: `3`

For horse→ros, one optimal sequence replaces h→r, deletes one r, deletes e, giving cost 3. Base dp[i][0]=i and dp[0][j]=j ensure empty-prefix cases are correct.

### D. Executable reference implementation

```python
"""Reference answer for A10. See the problem statement before reading.
"""
def solve(source, target):
    previous = list(range(len(target)+1))
    for i,a in enumerate(source,1):
        current = [i] + [0]*len(target)
        for j,b in enumerate(target,1):
            current[j] = min(previous[j]+1,current[j-1]+1,previous[j-1]+(a!=b))
        previous = current
    return previous[-1]
```

### E. Complexity derivation

O(nm) time for lengths n,m; the reference stores one previous and one current row of size m+1, so O(m) extra memory, not full O(nm) table.

### F. Failure modes that expose memorized solutions

Off-by-one mistakes occur when string character a[i−1] is confused with prefix length i. An operation script requires extra predecessor reconstruction not returned here.

### G. Transfer the technique

Variant: assign different costs to insert/delete/replace, then handle transpositions as an additional edit operation.
