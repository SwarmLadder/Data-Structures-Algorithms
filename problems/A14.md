# A14 — Count safe placements of n schedulers

**Hard** · Backtracking / constraints

## The challenge

Return the number of ways to place n queens on an n-by-n chessboard so none share a row, column or diagonal. Count different board arrangements separately. Define n=0 as one empty arrangement.

**Constraints:** 0 <= n <= 9.

**Function to implement:** `def solve(n):`

## Examples

1. Input arguments: `[4]` → expected output: `2`
2. Input arguments: `[1]` → expected output: `1`
