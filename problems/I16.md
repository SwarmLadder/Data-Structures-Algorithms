# I16 — Detect a loop in a linked chain

**Medium** · Fast and slow pointers

## The challenge

Represent a singly linked structure as next_index, where next_index[i] is a valid next index or -1 for null. Starting at start (-1 means empty), return True if following links ever repeats a node; otherwise False. Do not modify the array.

**Constraints:** 0 <= len(next_index) <= 100000; start is -1 or a valid index.

**Function to implement:** `def solve(next_index, start):`

## Examples

1. Input arguments: `[[1,2,3,1],0]` → expected output: `true`
2. Input arguments: `[[1,2,3,-1],0]` → expected output: `false`

### A. From baseline to the right data structure

A visited set catches repeated nodes in O(n) space. Floyd’s tortoise-and-hare method detects a cycle with two indices and O(1) extra space.

### B. Invariant or recurrence and why it works

Slow advances one link and fast two. On an acyclic path fast reaches -1; inside a cycle, the gap modulo cycle length changes by one per iteration and must eventually become zero.

### C. Work through a real example

- Function arguments: `[[1, 2, 3, 1], 0]`
- Expected output: `true`

For next_index=[1,2,3,1] starting at 0, the chain enters cycle 1→2→3→1. Slow/fast eventually coincide. A chain ending at -1 returns False.

### D. Executable reference implementation

```python
"""Reference answer for I16. See the problem statement before reading.
"""
def solve(next_index, start):
    def step(i):
        return -1 if i == -1 else next_index[i]
    slow = fast = start
    while fast != -1 and step(fast) != -1:
        slow = step(slow)
        fast = step(step(fast))
        if slow == fast:
            return True
    return False
```

### E. Complexity derivation

O(n) time (number of visited indices until termination or meeting) and O(1) auxiliary space.

### F. Failure modes that expose memorized solutions

Guard `fast != -1` and its successor before advancing twice. Compare node indexes/identities, not values that may repeat at different nodes.

### G. Transfer the technique

Variant: return the first cycle index and cycle length; derive the classic reset-one-pointer entry method.
