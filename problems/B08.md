# B08 — Rotate on-call assignments

**Easy** · Array indexing

## The challenge

Return a new array formed by rotating nums right by k positions. Handle k larger than the array length; an empty input stays empty.

**Constraints:** 0 <= len(nums) <= 100000; 0 <= k <= 10**9.

**Function to implement:** `def solve(nums, k):`

## Examples

1. Input arguments: `[[1,2,3,4,5],2]` → expected output: `[4,5,1,2,3]`
2. Input arguments: `[[1,2],3]` → expected output: `[2,1]`
