# B08 — Rotate on-call assignments

**Easy** · Array indexing

## The challenge

Return a new array formed by rotating nums right by k positions. Handle k larger than the array length; an empty input stays empty.

**Constraints:** 0 <= len(nums) <= 100000; 0 <= k <= 10**9.

**Function to implement:** `def solve(nums, k):`

## Examples

1. Input arguments: `[[1,2,3,4,5],2]` → expected output: `[4,5,1,2,3]`
2. Input arguments: `[[1,2],3]` → expected output: `[2,1]`

### A. From baseline to the right data structure

Performing k one-step rotations repeatedly is O(nk). Normalize k modulo n and use two slices, or reverse subranges for an in-place alternative.

### B. Invariant or recurrence and why it works

For a right rotation by k, the last k elements become the prefix, followed by the first n−k. This preserves relative order within each of the two groups. Handle empty input before computing k%n.

### C. Work through a real example

- Function arguments: `[[1, 2, 3, 4, 5], 2]`
- Expected output: `[4, 5, 1, 2, 3]`

For [1,2,3,4,5] and k=2, suffix [4,5] moves forward and prefix [1,2,3] moves afterward: [4,5,1,2,3]. k=7 gives the same answer after modulo 5.

### D. Executable reference implementation

```python
"""Reference answer for B08. See the problem statement before reading.
"""
def solve(nums, k):
    if not nums:
        return []
    k %= len(nums)
    return nums[-k:] + nums[:-k] if k else nums[:]
```

### E. Complexity derivation

Slicing builds O(n) output and takes O(n) time. The three-reversal in-place method is O(n) time and O(1) extra space.

### F. Failure modes that expose memorized solutions

A negative or zero shift may have separate semantics; use the stated contract. With k=0, Python’s `nums[-0:]` equals the entire array, not the empty suffix, so handle it separately.

### G. Transfer the technique

Variant: implement a left rotation and a three-reversal in-place right rotation, then compare mutation behavior.
