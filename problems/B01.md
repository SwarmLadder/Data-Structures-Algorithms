# B01 — Find a pair of matching transaction amounts

**Easy** · Hash map

## The challenge

Return the indices [i, j] (i < j) of two different elements whose sum equals target. Exactly one valid pair exists. Indices refer to the original input.

**Constraints:** 2 <= len(nums) <= 100000; signed integers; do not modify nums.

**Function to implement:** `def solve(nums, target):`

## Examples

1. Input arguments: `[[2,7,11,15],9]` → expected output: `[0,1]`
2. Input arguments: `[[3,3],6]` → expected output: `[0,1]`
