# B01 — Find a pair of matching transaction amounts

**Easy** · Hash map

## The challenge

Return the indices [i, j] (i < j) of two different elements whose sum equals target. Exactly one valid pair exists. Indices refer to the original input.

**Constraints:** 2 <= len(nums) <= 100000; signed integers; do not modify nums.

**Function to implement:** `def solve(nums, target):`

## Examples

1. Input arguments: `[[2,7,11,15],9]` → expected output: `[0,1]`
2. Input arguments: `[[3,3],6]` → expected output: `[0,1]`

### A. From baseline to the right data structure

The brute-force baseline checks all n(n−1)/2 pairs. A dictionary avoids rechecking earlier values: when looking at the current value x, ask whether target−x appeared before.

### B. Invariant or recurrence and why it works

At position j, `seen` maps prior values to indices smaller than j. Query **before** insertion so the same element is never selected twice. Because a unique valid pair is guaranteed, the matching prior position must be found when its later partner is processed.

### C. Work through a real example

- Function arguments: `[[2, 7, 11, 15], 9]`
- Expected output: `[0, 1]`

For [2,7,11,15] and target 9: record 2→0; at j=1, complement 2 is present, so return [0,1]. For [3,3], the second 3 finds the first even though the values are identical.

### D. Executable reference implementation

```python
"""Reference answer for B01. See the problem statement before reading.
"""
def solve(nums, target):
    seen = {}
    for j, x in enumerate(nums):
        i = seen.get(target - x)
        if i is not None:
            return [i, j]
        seen[x] = j
    raise ValueError('No matching pair')
```

### E. Complexity derivation

Expected O(n) time and O(n) dictionary space for integer keys. A nested-loop baseline takes O(n²) time and O(1) extra space.

### F. Failure modes that expose memorized solutions

Index 0 is a valid answer: `if seen.get(x)` rejects it. Inserting before searching can permit self-pairing. Sorting without preserving original indexes violates the contract.

### G. Transfer the technique

Variant: return **all** index pairs matching target (output can grow to Θ(n²)); explain why the output-size lower bound changes the complexity.
