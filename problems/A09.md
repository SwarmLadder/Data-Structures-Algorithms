# A09 — Longest strictly increasing deployment run (not necessarily contiguous)

**Medium** · Patience sorting / binary search

## The challenge

Return the length of the longest strictly increasing subsequence, which may skip elements. Equal values do not extend the subsequence.

**Constraints:** 0 <= len(nums) <= 100000.

**Function to implement:** `def solve(nums):`

## Examples

1. Input arguments: `[[10,9,2,5,3,7,101,18]]` → expected output: `4`
2. Input arguments: `[[0,1,0,3,2,3]]` → expected output: `4`
