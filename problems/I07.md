# I07 — Minimum concurrent worker slots

**Medium** · Min heap / scheduling

## The challenge

Each job occupies a half-open time interval [start,end). Return the minimum number of workers needed to run all jobs without overlap. A worker ending at t can start another job at t.

**Constraints:** 0 <= number of jobs <= 100000; start < end.

**Function to implement:** `def solve(jobs):`

## Examples

1. Input arguments: `[[[0,30],[5,10],[15,20]]]` → expected output: `2`
2. Input arguments: `[[[7,10],[2,4]]]` → expected output: `1`

### A. From baseline to the right data structure

A naive algorithm tests every candidate timestamp against all jobs. Sorting starts and tracking active end times in a min-heap exposes the next worker release in O(log n).

### B. Invariant or recurrence and why it works

The heap contains exactly jobs whose ends are greater than current start. Before adding a job, pop **all** ends ≤ start because intervals are half-open. The maximum heap size encountered equals minimum simultaneous workers required.

### C. Work through a real example

- Function arguments: `[[[0, 30], [5, 10], [15, 20]]]`
- Expected output: `2`

For jobs [0,30),[5,10),[15,20): heap sizes are 1,2; before job starting 15, finish 10 is removed, then finish 20 added, keeping 2. Answer 2.

### D. Executable reference implementation

```python
"""Reference answer for I07. See the problem statement before reading.
"""
def solve(jobs):
    import heapq
    ends = []
    answer = 0
    for start, end in sorted(jobs):
        while ends and ends[0] <= start:
            heapq.heappop(ends)
        heapq.heappush(ends, end)
        answer = max(answer, len(ends))
    return answer
```

### E. Complexity derivation

O(n log n) time from sorting, heap pushes and pops; O(n) heap memory. Each end is pushed and popped at most once.

### F. Failure modes that expose memorized solutions

Using `< start` rather than `<= start` counts a worker whose shift ended exactly at the next start as unavailable. Returning final heap size instead of the max misses earlier peaks.

### G. Transfer the technique

Variant: output an actual worker assignment with minimal IDs, not only the number of workers; add a free-worker-ID heap.
