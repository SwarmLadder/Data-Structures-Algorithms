# I07 — Minimum concurrent worker slots

**Medium** · Min heap / scheduling

## The challenge

Each job occupies a half-open time interval [start,end). Return the minimum number of workers needed to run all jobs without overlap. A worker ending at t can start another job at t.

**Constraints:** 0 <= number of jobs <= 100000; start < end.

**Function to implement:** `def solve(jobs):`

## Examples

1. Input arguments: `[[[0,30],[5,10],[15,20]]]` → expected output: `2`
2. Input arguments: `[[[7,10],[2,4]]]` → expected output: `1`
