# B04 — Check nested configuration delimiters

**Easy** · Stack

## The challenge

Return True when a string of round, square and curly brackets is properly matched and nested; otherwise False. The empty string is balanced.

**Constraints:** 0 <= len(text) <= 100000; every character belongs to ()[]{}.

**Function to implement:** `def solve(text):`

## Examples

1. Input arguments: `["([]){}"]` → expected output: `true`
2. Input arguments: `["([)]"]` → expected output: `false`

### A. From baseline to the right data structure

Counting opener and closer totals cannot detect wrong nesting: ([)] has matching totals but incorrect structure. Use a stack of unmatched opening brackets.

### B. Invariant or recurrence and why it works

The stack represents the unmatched opening symbols from the processed prefix in opening order. A closing symbol must match the top; otherwise no suffix can repair the already-invalid nesting. At the end, the stack must be empty.

### C. Work through a real example

- Function arguments: `["([]){}"]`
- Expected output: `true`

For ([]){}: push (, push [, pop [ on ], pop ( on ), push {, pop { on }; stack empty means true. For ([)], ) attempts to close [ and fails immediately.

### D. Executable reference implementation

```python
"""Reference answer for B04. See the problem statement before reading.
"""
def solve(text):
    pairs = {')': '(', ']': '[', '}': '{'}
    stack = []
    for ch in text:
        if ch in '([{':
            stack.append(ch)
        elif not stack or stack.pop() != pairs[ch]:
            return False
    return not stack
```

### E. Complexity derivation

One push or pop per character gives O(n) time and O(n) stack space in the all-opening worst case.

### F. Failure modes that expose memorized solutions

Reject a closing symbol with empty stack. An empty input is balanced. Treat only ()[]{} because the contract restricts the alphabet; arbitrary text would need an explicit policy.

### G. Transfer the technique

Variant: return the index of the **first** invalid closer, or −1 if the string is valid, and specify the behavior of leftover openers.
