# B04 — Check nested configuration delimiters

**Easy** · Stack

## The challenge

Return True when a string of round, square and curly brackets is properly matched and nested; otherwise False. The empty string is balanced.

**Constraints:** 0 <= len(text) <= 100000; every character belongs to ()[]{}.

**Function to implement:** `def solve(text):`

## Examples

1. Input arguments: `["([]){}"]` → expected output: `true`
2. Input arguments: `["([)]"]` → expected output: `false`
