# B15 — Longest shared route prefix

**Easy** · Strings

## The challenge

Return the longest prefix shared by every string in paths. If paths is empty, return "". Matching is case-sensitive.

**Constraints:** 0 <= len(paths) <= 20000; total characters <= 100000.

**Function to implement:** `def solve(paths):`

## Examples

1. Input arguments: `[["flower","flow","flight"]]` → expected output: `"fl"`
2. Input arguments: `[["dog","racecar","car"]]` → expected output: `""`

### A. From baseline to the right data structure

Compare strings against a candidate prefix, shrinking it whenever a new path does not start with it. At any point the candidate is a common prefix of all strings processed so far.

### B. Invariant or recurrence and why it works

Starting with the first string, remove trailing characters until each following string begins with the candidate. A common prefix cannot grow when additional strings are considered, so every shrink is irreversible and safe.

### C. Work through a real example

- Function arguments: `[["flower", "flow", "flight"]]`
- Expected output: `"fl"`

For [flower,flow,flight], first two share flow. Against flight, flow shrinks to flo, fl, and stops at fl: this is the longest common prefix.

### D. Executable reference implementation

```python
"""Reference answer for B15. See the problem statement before reading.
"""
def solve(paths):
    if not paths:
        return ''
    prefix = paths[0]
    for path in paths[1:]:
        while not path.startswith(prefix):
            prefix = prefix[:-1]
        if not prefix:
            return ''
    return prefix
```

### E. Complexity derivation

The repeated `startswith` plus Python prefix slicing may cost more than O(total input characters) in the worst case; for m strings and initial length L a conservative bound is O(mL+L²). A direct column-wise scan yields O(mL) with L bounded by shortest string length.

### F. Failure modes that expose memorized solutions

On empty input return an empty prefix. Do not assume strings share lengths. Unicode normalization is a separate contract not implied by prefix comparison.
