# B15 — Longest shared route prefix

**Easy** · Strings

## The challenge

Return the longest prefix shared by every string in paths. If paths is empty, return "". Matching is case-sensitive.

**Constraints:** 0 <= len(paths) <= 20000; total characters <= 100000.

**Function to implement:** `def solve(paths):`

## Examples

1. Input arguments: `[["flower","flow","flight"]]` → expected output: `"fl"`
2. Input arguments: `[["dog","racecar","car"]]` → expected output: `""`
