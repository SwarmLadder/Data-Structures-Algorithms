# I15 — Lowest shared manager in a BST

**Medium** · Tree search

## The challenge

The input tree uses heap-style indexing, is a valid BST with distinct integer values, and contains p and q. Return the value of their lowest common ancestor. A node can be an ancestor of itself.

**Constraints:** 1 <= number of reachable nodes <= 100000.

**Function to implement:** `def solve(tree, p, q):`

## Examples

1. Input arguments: `[[6,2,8,0,4,7,9,null,null,3,5],2,8]` → expected output: `6`
2. Input arguments: `[[6,2,8,0,4,7,9,null,null,3,5],2,4]` → expected output: `2`

### A. From baseline to the right data structure

A general binary-tree LCA may require traversing both subtrees. In a BST, compare both query keys with the current value to decide whether the LCA lies left, right or here.

### B. Invariant or recurrence and why it works

If both targets are smaller than x, both lie in the left subtree; if both are larger, go right. Otherwise they split across subtrees or one equals x, so x is their lowest shared ancestor.

### C. Work through a real example

- Function arguments: `[[6, 2, 8, 0, 4, 7, 9, null, null, 3, 5], 2, 8]`
- Expected output: `6`

In BST rooted at 6 with 2 on the left and 8 on the right, LCA(2,8)=6 immediately. For targets 2 and 4 inside the left subtree, descend to 2 and stop there.

### D. Executable reference implementation

```python
"""Reference answer for I15. See the problem statement before reading.
"""
def solve(tree, p, q):
    i = 0
    lo, hi = sorted((p,q))
    while i < len(tree):
        x = tree[i]
        if lo <= x <= hi:
            return x
        i = 2*i + 1 if hi < x else 2*i + 2
    raise ValueError('Missing node')
```

### E. Complexity derivation

O(h) time and O(1) extra space by iterative descent; h is O(log n) balanced and O(n) skewed.

### F. Failure modes that expose memorized solutions

The course uses an index-encoded BST. Input keys are assumed present; if missing keys were allowed, extra existence validation would be needed.
