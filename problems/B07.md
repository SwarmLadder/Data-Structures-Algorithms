# B07 — Largest consecutive net gain

**Medium** · Dynamic programming

## The challenge

Return the maximum sum over all nonempty contiguous subarrays. If every number is negative, return the largest (least negative) number.

**Constraints:** 1 <= len(nums) <= 100000; signed integers.

**Function to implement:** `def solve(nums):`

## Examples

1. Input arguments: `[[-2,1,-3,4,-1,2,1,-5,4]]` → expected output: `6`
2. Input arguments: `[[-3,-7,-1]]` → expected output: `-1`

### A. From baseline to the right data structure

Checking every start/end pair is quadratic or cubic with repeated summing. Kadane’s method keeps the best nonempty subarray sum that ends exactly at the current index.

### B. Invariant or recurrence and why it works

For current x, a best range ending here either starts at x or extends the best ending at the previous index. So running=max(x,running+x). Global best is the largest running seen so far; this covers every nonempty contiguous range.

### C. Work through a real example

- Function arguments: `[[-2, 1, -3, 4, -1, 2, 1, -5, 4]]`
- Expected output: `6`

For [-2,1,-3,4,-1,2,1,-5,4], the winning run begins at 4 and extends through −1,2,1, reaching 6. The algorithm restarts whenever extending a negative prior run would be worse.

### D. Executable reference implementation

```python
"""Reference answer for B07. See the problem statement before reading.
"""
def solve(nums):
    best = running = nums[0]
    for x in nums[1:]:
        running = max(x, running + x)
        best = max(best, running)
    return best
```

### E. Complexity derivation

O(n) time. A range-indexed loop uses O(1) extra space. The existing reference’s `nums[1:]` slice creates O(n) temporary memory; avoid the slice if you require a strict O(1)-auxiliary implementation.

### F. Failure modes that expose memorized solutions

Initializing best=0 wrongly returns zero for an all-negative nonempty array. The required range is contiguous: choosing all positive values from disconnected positions is invalid.
