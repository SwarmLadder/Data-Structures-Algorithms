# I06 — Insert a maintenance window into a schedule

**Medium** · Intervals / sweep

## The challenge

Existing intervals are sorted, pairwise disjoint, closed [start,end] intervals. Insert new_interval, merge any overlapping or touching intervals, and return the updated sorted schedule.

**Constraints:** 0 <= len(intervals) <= 100000; start <= end; original intervals are disjoint and do not touch.

**Function to implement:** `def solve(intervals, new_interval):`

## Examples

1. Input arguments: `[[[1,3],[6,9]],[2,5]]` → expected output: `[[1,5],[6,9]]`
2. Input arguments: `[[[1,2],[3,5],[6,7],[8,10],[12,16]],[4,8]]` → expected output: `[[1,2],[3,10],[12,16]]`

### A. From baseline to the right data structure

If existing intervals are already sorted and nonoverlapping, inserting a new interval does not require a full re-sort. Scan three regions: strictly before, overlapping, strictly after.

### B. Invariant or recurrence and why it works

All prior intervals with end < new start may be copied unchanged. While an interval starts ≤ the merged end, absorb it by extending min start/max end. Once overlap ends, append the merged interval then copy the remaining suffix.

### C. Work through a real example

- Function arguments: `[[[1, 3], [6, 9]], [2, 5]]`
- Expected output: `[[1, 5], [6, 9]]`

Insert [4,8] into [[1,2],[3,5],[6,7],[8,10],[12,16]]: copy [1,2]; merge [3,5],[6,7],[8,10] into [3,10]; copy [12,16].

### D. Executable reference implementation

```python
"""Reference answer for I06. See the problem statement before reading.
"""
def solve(intervals, new_interval):
    result = []
    a,b = new_interval
    i=0
    while i<len(intervals) and intervals[i][1] < a:
        result.append(intervals[i][:]); i+=1
    while i<len(intervals) and intervals[i][0] <= b:
        a=min(a, intervals[i][0]); b=max(b, intervals[i][1]); i+=1
    result.append([a,b])
    result.extend([v[:] for v in intervals[i:]])
    return result
```

### E. Complexity derivation

O(n) time and O(n) output space with existing sorted/nonoverlapping input. No sorting is needed because the precondition is part of the contract.

### F. Failure modes that expose memorized solutions

If original intervals are unordered or already overlapping, this three-region method may fail. Closed endpoint contact at 8 counts as overlap here.
