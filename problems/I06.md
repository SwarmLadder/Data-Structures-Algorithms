# I06 — Insert a maintenance window into a schedule

**Medium** · Intervals / sweep

## The challenge

Existing intervals are sorted, pairwise disjoint, closed [start,end] intervals. Insert new_interval, merge any overlapping or touching intervals, and return the updated sorted schedule.

**Constraints:** 0 <= len(intervals) <= 100000; start <= end; original intervals are disjoint and do not touch.

**Function to implement:** `def solve(intervals, new_interval):`

## Examples

1. Input arguments: `[[[1,3],[6,9]],[2,5]]` → expected output: `[[1,5],[6,9]]`
2. Input arguments: `[[[1,2],[3,5],[6,7],[8,10],[12,16]],[4,8]]` → expected output: `[[1,2],[3,10],[12,16]]`
