# End-to-end projects

These three projects combine interview patterns into small, testable programs. They are **manual projects**, not automatically graded. Each specification gives concrete function inputs, output contracts and acceptance tests. Work in Python with only the standard library.

1. **[Log signal analyzer](01_log_signal_analyzer.md)** — Basics: frequency tables, ordered events and range sums.
2. **[Worker scheduler](02_job_scheduling_engine.md)** — Intermediate: interval semantics, heaps and deterministic resource allocation.
3. **[Deployment planner](03_dependency_planner.md)** — Advanced: DAG scheduling, critical paths and minimum networks.
